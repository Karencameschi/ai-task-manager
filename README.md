AI Task Manager

Aplicação web que analisa suas tarefas usando IA. Você descreve o que precisa fazer e o app retorna a prioridade, tempo estimado, dificuldade, subtarefas e alguma dica.
Construido com Python, Flask e a API do Claude (Anthropic).

Tecnologias:
Python 3 + Flask
Anthropic Claude API
HTML, CSS e JavaScript vanilla


Passo a passo para rodar o projeto localmente:

1 - Ter o Python instalado
2 - Clonar o repositório (Abrir o terminal e executar Git Clone )
3 - Instalar as dependencias (Tudo que tiver listado no requerimentos: pip install -r requirements.txt)
4 - Configurar a variável (Criar um arquivo .env na raiz do projeto e inserir a credencial da Antrhopic para o funcionamento da IA: ANTHROPIC_API_KEY=)
5 - Executar o arquivo (python app.py)
